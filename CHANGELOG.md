## Release 1.0.3
- Added new matching options in settings: match raid markers, match digits, and match my name. Mouse over them to see a tooltip explaining each one.
- Reformatted the Settings window.
- Fixed a bug with how the minimized window is saved on /reload or logout.
- Added a new option: /rp-parse reset. This will un-minimize the viewer window, center it, and reset the size to its default.

## Release 1.0.2
- Added a keyword list under settings. Users may now customize the keywords the addon looks for. It continues to monitor for digits and raid symbols even if this box is cleared.
- Adjusted click through behavior. Double right click deletes a single row. Middle mouse click opens the whisper dialogue.

## Release 1.0.1
- Changed the command to display the viewer to /rp-parse
